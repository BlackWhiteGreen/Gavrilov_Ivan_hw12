# Анализатор PCAP трафика

Репозиторий содержит Python-скрипт для анализа сетевых дампов (`.pcap`). Скрипт автоматизирует процесс извлечения ключевых артефактов (IP-адреса, DNS-запросы) и строит визуализацию наиболее активных узлов в сети.

---

**ВНИМАНИЕ:** Этот проект создан исключительно в образовательных целях и для практики в области сетевой форензики (Digital Forensics). 

1. Файл трафика, используемый в коде, содержит активность реального вредоносного ПО (**GuLoader** и **AgentTesla**).
2. Автор не несет ответственности за любые последствия, вызванные запуском скрипта или неосторожным обращением с вредоносными данными.
3. **Рекомендация:** Всегда проводите анализ подозрительных `.pcap` файлов в изолированной среде (Virtual Machine или Sandbox).
